Changes in this add-on, 2026-09-28:
The prompt/readout logic is adapted to JavaScript and a local llama.cpp server.
The official vLLM/MLX transport is not used. It reuses Open Jev Bridge's native
llama.cpp probability validation and equal-bias recovery. Structured inputs
are rendered as JSON, not Python repr. Large option sets use the upstream
hierarchical composition with bounded sequential execution. Loopback-only
HTTP endpoints, request limits, cancellation and model alias checks are added.
No upstream endorsement or live-model accuracy parity is claimed.
